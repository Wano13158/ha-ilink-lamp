# iLink Light - Home Assistant Integration (Fixed & Merged)

Интеграция для управления Bluetooth-люстрами и лампами **iLink** (чипы JieLi / JL, сервис `0000a032-0000-1000-8000-00805f9b34fb`) через Home Assistant.

Этот модуль объединяет стабильную архитектуру клиента (Bluetooth discovery, Config Flow, координатор) и рабочий протокол управления цветом (RGB) и яркостью на основе логов btsnoop официального приложения.

---

## Что было исправлено и объединено

1. **Исправлено переключение и сброс RGB цвета:**
   - В исходном модуле `ilink_light` сразу после команды установки RGB вызывалась функция `set_brightness()`, которая отправляла команду белого света (`01 08 01...`), из-за чего лампа мгновенно сбрасывала цвет и возвращалась в белый режим либо гасла.
   - Теперь режимы **RGB** и **Белый свет (Color Temp)** разделены: при выборе цвета отправляется пакет с нужным оттенком и текущей яркостью без переключения в белый режим.

2. **Интегрирован пакет команд RGB из btsnoop логов:**
   - Внедрен пакет `0x55, R, G, B, Brightness, 0xFF, 0xF0` из рабочего сниффа Bluetooth-трафика официального приложения `iLink` (`com.jwtian.smartbt`).
   - Дополнительно дублируется команда `55aa030802...` для совместимости со всеми ревизиями прошивок контроллера.

3. **Раздельная регулировка яркости:**
   - В режиме **RGB** ползунок яркости меняет яркость цветных диодов через RGB-пакет, не переключая люстру на белый свет.
   - В режиме **Color Temp** ползунок яркости управляет белыми диодами (`55aa010801...`).

4. **Надежное выключение:**
   - При выключении отправляются обе команды: стандартная `55aa01080500f2` и пакет выключения из логов `0x55, 0x00, 0x00, 0x00, 0x00, 0x00, 0xF0`, гарантируя отключение как цветных, так и белых светодиодов.

5. **Корректные GATT-характеристики и устранение таймаутов Bleak:**
   - Нерабочий прототип использовал несуществующий UUID `0000ffe1-...`.
   - Теперь команды автоматически отправляются на поддерживаемые характеристики лампы: `0000a044` (Write without response) или `0000a040` (Write), что исключает ошибки подключения и зависания Bleak на 10 секунд.

6. **Совместимость с современными версиями Home Assistant (2024+):**
   - Устранено предупреждение об отсутствии `await` для `async_forward_entry_setups`.
   - Удалены устаревшие вызовы приватного метода `_async_schedule_save()`.
   - `async_timeout` заменен на встроенный `asyncio.timeout`.
   - Исправлена опечатка в шкале цветовой температуры (`600 -> 6000`).

## Установка

### Вариант 1: Копирование папки (вручную)
1. Скопируйте папку `custom_components/ilink_light` в вашу директорию Home Assistant:
   ```text
   /config/custom_components/ilink_light
   ```
2. Перезапустите Home Assistant.
3. Перейдите в **Настройки** -> **Устройства и службы** -> **Интеграции**.
4. Нажмите **Добавить интеграцию** и найдите **iLink Light** (или дождитесь автоматического обнаружения по Bluetooth).

### Вариант 2: Через HACS
1. В HACS откройте меню (три точки в правом верхнем углу) -> **Пользовательские репозитории**.
2. Вставьте ссылку на репозиторий с этим проектом, выберите категорию **Интеграция**.
3. Установите и перезапустите Home Assistant.

## Поддерживаемые функции
- Включение / выключение (Power On/Off)
- Выбор цвета (RGB Color Wheel)
- Регулировка яркости как для цветного, так и для белого света (Brightness)
- Регулировка цветовой температуры (3000K – 6000K)
- Эффекты и сцены (Rainbow, Flowing, Sleep и др.)
- Автоматическое обнаружение по Bluetooth (Bluetooth Discovery)
